Komponen & Deskripsi Tingkat Kerumitan Nilai Komponen
```
Sistem Autentikasi Mandiri
Login, register, forgot & reset password dengan token 1 jam, session management, SHA--256 salted hashing, max--user slot enforcement, dan user count UI -- seluruhnya tanpa backend server eksternal. Mencakup edge case: token kadaluarsa, email tidak terdaftar, password mismatch, slot penuh.
Tinggi
Rp 8.400.000
Auth Penuh
Dual Backend Transparan
Satu codebase berjalan identik di IndexedDB lokal ATAU Firebase Firestore -- tanpa perubahan logika bisnis. Auto--fallback bila Firebase tidak tersedia. Real--time sync badge. Arsitektur adapter pattern murni dalam single--file HTML; sangat langka dan membutuhkan disiplin engineering tinggi.
Sangat Tinggi
Rp 9.600.000
Arsitektur Unik
Dashboard Outlet Multi--Kolom
Grid 1--3 kolom adaptif dengan collapse/expand per outlet, sistem color identity 12 palet berbasis hash ID (konsisten tanpa konfigurasi), KPI card animasi, hero stats, filter bar. UX didesain untuk scanability cepat oleh supervisor multi--lokasi.
Tinggi
Rp 6.600.000
UX Kompleks
Sistem Manajemen Kontrak
Update kontrak dengan preview real--time, kalkulasi dari titik referensi fleksibel (akhir kontrak aktif atau hari ini), pilih bulan/tahun dengan auto--round ke akhir bulan, history log per karyawan dengan timestamp penuh. Business logic edge case ditangani menyeluruh.
Tinggi
Rp 5.400.000
Logic Bisnis
Kamus Gender Indonesia (370+ Nama)
Kamus terverifikasi manual 166 nama Naruna + 200+ nama umum Indonesia. Algoritma skip--ambigu (DWI, WAHYU, TRI, dll.) dengan infer dari token berikutnya. Auto--guess dari nama input baru. Override manual. Fallback suffix regex. Tidak ada library publik yang menyediakan ini -- dikembangkan dari nol.
Sangat Tinggi
Rp 4.200.000
IP Unik
Import Excel Multi--Sheet Cerdas
Auto--detect header row di 10 baris pertama, 30+ alias kolom (Nama Karyawan / Employee Name / NAMA, dll.), parser tanggal 6 format termasuk serial number Excel, nama sheet sebagai fallback outlet. Dedup logic. Toleran terhadap format file "kotor" dari HR yang tidak konsisten.
Sangat Tinggi
Rp 7.200.000
Production--Grade
Notifikasi & Monitoring Real--time
Bell animasi pulse, panel notifikasi slide--in, count badge, threshold 30 hari, sorting urgensi otomatis, warning/danger state dengan visual berbeda, dismiss saat klik luar. Dirancang agar tidak mengganggu workflow saat tidak dibutuhkan.
Sedang
Rp 3.000.000
UX Polish
UI/UX Design System Lengkap
Dark/light mode penuh, 50+ CSS custom properties, Instrument Serif + Geist typography system, noise texture overlay, topbar sticky dengan backdrop blur, toast notification system, animated loading screen, responsive mobile. Kualitas setara design system agency premium.
Sangat Tinggi
Rp 9.100.000
Premium Design
Export & Backup Data
Export JSON backup berversi dengan metadata, export CSV dengan BOM UTF--8 (agar terbaca benar di Excel Indonesia), restore JSON dengan sanitasi dan validasi schema, preview import sebelum overwrite, konfirmasi dua langkah untuk operasi destruktif.
Sedang
Rp 2.400.000
Data Safety
Dashboard Analitik Global
Tampilan lintas seluruh outlet: agregasi kritis/aman/tanpa--tanggal, statistik per outlet dengan progress bar visual, navigasi kontekstual langsung ke update kontrak karyawan spesifik. Dirancang untuk keputusan cepat di level manajemen.
Sedang
Rp 3.000.000
Analytics
Keamanan & Ketahanan Data
safeText/safeNumber sanitasi di setiap input, escapeHtml pada semua output DOM, debounce pada semua operasi berat, normalizeText untuk pencarian fuzzy, validasi email regex, password confirm, konfirmasi sebelum hapus data. Tidak ada XSS surface yang dibiarkan terbuka.
```

Catatan metodologi: Nilai tiap komponen ditentukan berdasarkan tiga faktor utama: (1) kerumitan logika teknis dan jumlah edge case yang ditangani, (2) kualitas output dan keunikan solusi di pasar lokal, serta (3) nilai bisnis langsung yang diberikan kepada pengguna akhir. Estimasi ini tidak bergantung pada waktu pengerjaan aktual -- sebuah solusi yang diselesaikan lebih cepat oleh developer berpengalaman tidak berarti nilainya lebih rendah.
