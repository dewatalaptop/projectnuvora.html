02
Nilai Diferensiasi
Fitur Premium yang Menentukan Harga
🧠
AI Gender Dictionary Indonesia
Kamus 370+ nama terverifikasi dengan logika skip-ambigu (DWI, WAHYU, TRI, dll) dan fallback suffix regex. Tidak ada library publik yang menyediakan ini untuk nama Naruna secara spesifik.
Nilai unik: Rp 4.200.000
🔄
Dual Backend Transparan
Satu codebase berjalan di IndexedDB lokal ATAU Firebase Firestore tanpa perubahan logika bisnis. Auto-fallback bila Firebase gagal. Sangat langka dalam single-file HTML app.
Nilai unik: Rp 9.600.000
📊
Import Excel Multi-Sheet Cerdas
Auto-detect header di 10 baris pertama, 30+ alias kolom, parse tanggal 6 format berbeda termasuk serial Excel, nama sheet sebagai fallback outlet. Production-grade.
Nilai unik: Rp 7.200.000
🎨
Design System 12 Outlet Identity
Sistem warna dinamis berbasis hash ID outlet - setiap outlet selalu mendapat warna konsisten dari 12 palet tanpa konfigurasi. Dark mode penuh dengan 50+ token CSS.
Nilai unik: Rp 4.500.000
📜
History Kontrak Lengkap Per Karyawan
Setiap update kontrak tersimpan dengan timestamp, tanggal lama, tanggal baru, durasi, dan keterangan. Audit trail penuh yang bisa di-review kapan saja.
Nilai unik: Rp 2.100.000
🔐
Auth Mandiri + Reset Password Email
Sistem auth lengkap tanpa layanan pihak ketiga: SHA-256 salted hashing, token reset 1 jam via EmailJS, slot max user, tanpa backend server.
Nilai unik: Rp 8.400.000
